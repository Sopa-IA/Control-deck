# Orbit Terminal - Manual de montaje y software

Este es el manual vigente. Sustituye a `docs/manual_montaje/` y a `docs/manual-montaje/`.

La fuente es `hardware/cad/manual/completo_pdf.py` y `hardware/cad/manual/completo.scad`.
Para regenerarlo, desde la raíz del repo:

```
python3 hardware/cad/manual/completo_pdf.py
```

PDF: `docs/manual_completo/Orbit_manual_completo.pdf`. Páginas: 93. Pasos numerados: 79.

Cada paso numerado tiene su figura. Lo naranja es lo que se pone en ese paso. Las pantallas de Imager y las cajas de terminal son ilustraciones, rotuladas en la propia figura.

La carcasa y la base ya están impresas y cerradas. No se cortan, no se taladran y no se liman. La tapa de la Pi es la v2. La bandeja es la v3, con ventanas. El soporte de un ventilador soplante no existe: queda pendiente.
